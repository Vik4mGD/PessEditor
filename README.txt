PESS EDITOR 0.8.3

A simple video editor for Windows.

BUILDING FROM SOURCE

1. Install Python.
2. Open PowerShell in the Build directory.
3. Install the required dependencies:

```
python -m pip install -r requirements.txt
```

4\. Run the build script:

```
.\build.ps1
```

SOURCE CODE

The main application source code is located in:

`Source/main.py`

RUNNING THE APPLICATION

Run `PessEditor.exe` to launch the application.

RESOURCES

- Application icon: `Resources/pess.ico`
- FFmpeg and FFprobe are bundled with the application.
